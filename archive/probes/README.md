# Historical probe workflow

The probe workflow attached linear digit classifiers and image reconstructors to states produced by a frozen, older SGLR backbone. It was useful for inspecting latent contents but is not a causal test of expert contribution: visited samples differ by digit, difficulty, route position, and their prior latent state.

Probe results should not be described as proof that the selected expert added class information. The focused experiment instead records pre-specified routing controls and held-out route statistics.
